# Telemicro Informática

Landing page da Telemicro Informática, migrada para Angular standalone.

## Executar localmente

```bash
npm install
npm start
```

A aplicação ficará disponível em `http://localhost:4200/`.

## Estrutura

- `src/app/components`: cabeçalho e rodapé reutilizáveis.
- `src/app/pages/home`: landing page, carrossel e formulário de orçamento.
- `src/app/core`: modelos e serviço de carregamento dos dados.
- `src/assets`: imagens e JSON de licitações.

## Build de produção

```bash
npm run build
```
